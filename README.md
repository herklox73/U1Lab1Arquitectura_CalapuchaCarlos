# U1 Lab1 Arquitectura - Calapucha Carlos

Aplicación Flask con un pipeline de filtros (carga, validación, preparación, entrenamiento y evaluación) para un modelo de clasificación con scikit-learn.

## Cómo ejecutar

```bash
python -m venv venv
venv\Scripts\activate        # Windows
pip install -r requirements.txt
python app.py
```
